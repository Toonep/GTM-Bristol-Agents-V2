# bristol-lead-sourcer

Lead sourcing pipeline for Bristol GTM — aggregates business leads from multiple sources (Google Places, Apollo, SerpAPI, Hunter) for home services targeting.

## Setup

```bash
cp .env.example .env
# Fill in API keys in .env
npm install
```

## Usage

```bash
npm start
```

## Configuration

Edit `config.json` to adjust industry, specialty, target states, and lead targets.
